# Financial Tracking App

Currently I Track my finances using an excel sheet that I have to update manually and run all calculation functions by hand. I want to make an app that does these calculations and tracking for me.

## Sections
* Debts - Time to pay off, interest calculations, timeline to pay off, calendar to show when amounts change
* Savings - Saving goals, interest calculations based on APR, options for multiple accounts, calendar to show savings timeline and adjust with a varied rate of deposit
* Needs based payments - Make amount based suggestions where spending can be decreased, correctly categorize needs/wants, factor in yearly payments into monthly savings cost
* Pet food allocation - Input the food cost and the rate of usage to calculate the amount needed monthly for food
* Spending chart and percentages - Allow user to view categories in spending in a non-table format

## Future Ideas; not guaranteed
* Connect to financial accounts for real time spending/saving reports
* Mobile compatibility
* Custom Allocation script - allow feature to be used for things other than pet food, for things such as cloud usage on webapps
* Investments and stocks portfolio tracking
